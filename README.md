# Tender-Flow-Releases
Veřejné instalační soubory a aktualizace Tender Flow. Zdrojový kód je veden odděleně.

Podepsaná pravidla spuštění Windows se automaticky obnovují ze soukromého
repozitáře aplikace. Zdejší workflow `Desktop policy expiry watchdog` dvakrát
denně nezávisle ověřuje podpis, shodu obou veřejných kopií a rezervu přes 14 dní.
Nepoužívá žádné přihlašovací údaje a nemění instalátory ani pravidla.
Selhání se hlásí standardními oznámeními GitHub Actions podle nastavení správce.
